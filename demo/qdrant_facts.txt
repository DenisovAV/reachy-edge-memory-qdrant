# What the robot knows about Qdrant. A line "question | fact" starts a fact:
# the fact is what the robot says, spoken aloud as-is. Each line after it that
# ends in a bare "|" is one more way to ask the same thing. The questions are
# what a search compares against — never said — stored on the fact's one point
# as a multivector (demo/knowledge.py): a short question finds an equally
# short question far better than it finds the long sentence that answers it.
#
# After editing: `uv run python -m demo.knowledge build` (demo/stage.py does it
# for you when this file is newer than demo/qdrant_knowledge.snapshot).
